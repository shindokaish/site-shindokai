Edge Function — Synchronisation membres

Permet au dashboard d'importer tous les comptes Supabase Auth (y compris les anciens membres). À configurer une fois dans le dashboard Supabase.

Instructions de déploiement →
1. Ouvre supabase.com/dashboard
2. Projet shindokai → Edge Functions → New function → nom : list-members
3. Colle le code depuis supabase/functions/list-members/index.ts
4. Settings → Secrets → ajoute ADMIN_SECRET_TOKEN = un mot de passe de ton choix
5. Reviens ici, entre l'URL et ce token, Enregistre
